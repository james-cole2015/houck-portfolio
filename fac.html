Field Assessment Console

Offline-first security assessment platform for field engagements

Built by a practitioner who needed it: a local web application for structured, compliance-grade vulnerability and configuration assessment that operates on disconnected networks and produces audit-ready POA&M, OSCAL, and report outputs without manual formatting overhead.

Explore

The Problem

Field assessors need structured tooling. Most of what exists assumes connectivity, a mature security stack, or both.

Manual Patch Lookup

Comparing installed OS versions and packages against vendor advisories by hand is slow, error-prone, and doesn't scale across dozens of assets in a single engagement.

Connectivity Constraints

On-site assessment environments frequently have no internet access. Tooling that depends on cloud connectivity fails at exactly the wrong moment, mid-engagement.

Reporting Overhead

Translating raw findings into a POA&M, formatting OSCAL XML, and generating per-asset decision worksheets can consume hours that should be spent on analysis.

No Findings Lifecycle

Without purpose-built tooling, decisions and remediation status get tracked across spreadsheets with no audit trail linking back to the specific findings that drove them.

How It Works

A two-phase design separates internet-dependent data collection from on-site assessment, enabling fully air-gapped operation where it matters most.

Collection Scripts - Auto-generated PowerShell (Windows) and Bash (Linux) scripts require no elevated privileges and produce base64-encoded output for secure transport across air-gapped networks.

Assessment Pipelines

Six distinct workflows cover the full scope of enterprise patch and configuration assessment.

Windows - Modern

Compares Update Build Revision (UBR) against Microsoft Security Response Center KB data for Windows 10/11 and Server 2016–2025.

Windows - Legacy

KB list comparison for end-of-life systems - Windows 7, 8.1, and Server 2008 R2 through 2012 R2 - with pre-built EOL caches included.

Linux

Package advisory matching across Debian, Ubuntu, RHEL, CentOS, Rocky Linux, and AlmaLinux with source package mapping and kernel alias handling.

Third-Party Software

Evaluates 27+ curated Windows software titles - browsers, Java runtimes, PDF readers, VPN clients, and more - against NVD CVE data.

CIS Configuration

Tests system configuration compliance against CIS benchmarks loaded via Excel workbooks, with per-control pass/fail tracking and deviation notes.

Scanner Import

Imports vulnerability and configuration findings from Tenable Nessus and Qualys CSV exports with optional EPSS and CISA KEV enrichment.

AI Integration

AI is woven into two distinct workflows: enriching findings during an assessment, and keeping the tool's reference catalogs current over time.

During Assessments

POA&M Narrative Generation

Generates structured remediation context for each finding - what to patch, why it matters, and compensating controls when immediate patching isn't possible. Each finding entry includes CVE IDs, CVSS score, EPSS probability, and KEV status so the LLM produces actionable, risk-calibrated remarks.

Works via Claude API with a live key, or exports a structured .md prompt for use in any enterprise or air-gapped LLM. Includes a data classification notice reminding assessors to verify their LLM is approved before pasting.
EPSS & CISA KEV Enrichment

Exploit Prediction Scoring System data enriches each CVE with an active exploitation probability, surfacing high-risk findings that raw CVSS scores would otherwise bury. The CISA Known Exploited Vulnerabilities catalog flags findings under active exploitation by threat actors - the highest-confidence signal for prioritization.

Both datasets are fetched during pre-assessment and applied offline. EPSS scores and KEV status are embedded directly into the exported POA&M prompt so narratives are exploitation-aware.

Catalog Maintenance

CIS Benchmark Version Check

Generates a ready-to-paste prompt listing all currently loaded CIS benchmarks (name and version). Feed it into any enterprise LLM with web browsing - Copilot, ChatGPT, or similar - and it returns whether newer benchmark versions are available, so the operator knows when to source an updated workbook.

CPE Lookup for New Software

When an operator wants to add a software title to the third-party assessment catalog, they need a valid CPE 2.3 string to query NVD. This generates a targeted prompt - with the software name interpolated in - for any web-browsing LLM to return the correct CPE identifier, which can then be added as a custom catalog entry.

What's Next

Two features currently in active development.

In Development
CVE Cross-Reference Callouts

When the same CVE appears across multiple pipelines - a Windows KB, a Linux package, and a third-party app all sharing the same CVE - the tool currently has no way to surface that connection. This feature adds a collapsible cross-reference summary to the findings view and a dedicated detail page showing per-pipeline blast radius on a single screen.

In Development
Nessus Host Metadata Enrichment

Adds native .nessus XML import alongside the existing Tenable CSV path, enriching each asset with OS version, BIOS detail, credentialed scan status, and assessor-supplied ownership fields. Results surface as an OS distribution summary across the import batch and per-asset host context throughout reports and exports.
